About / Guide
Instructions, system requirements, and CLI reference for the Build Tool.
How to Use
  1. General Tab — Enter application info (name, version, icon)
  2. Code Protection Tab — Choose desired obfuscation settings and security layers
  3. Restrictions Tab — Configure IP lock, time-lock expiry, and authorized machine IDs
  4. Build & Export Tab — Select target platform (Windows/macOS/Linux), target output type (Web Server, Desktop, or Both), and click Start Build
CLI Alternative Examples
# Build simple web binary (Flask server only) python build_tool/builder_cli.py --target web # Build both targets on macOS (requires macOS host) python build_tool/builder_cli.py --target both --platform macos # Build with full protection (PyArmor, AST scrambling, IP lock, & expiry) python build_tool/builder_cli.py --target both --obfuscate --ip-lock 1.2.3.4 --expire 2027-12-31 # Show this machine's fingerprint ID python build_tool/builder_cli.py --machine-id-info # Open this Build Tool GUI server python build_tool/builder_cli.py --gui
CLI Parameters Reference
Parameter Value / Choice Description
--target web, desktop, both Compilation target: Flask backend server only, Electron app only, or both.
--platform windows, macos, linux, auto Target OS format. auto autodetects host OS. Cross-compilation is not supported.
--obfuscate None Enables AST code protection, dead code injection, string encoding, and PyArmor.
--ip-lock IP List Lock run to whitelisted public IPs (space-separated list). Queries public IP APIs on startup.
--expire YYYY-MM-DD Time lock expiration date. Standalone executables will exit after this date.
--machine-ids ID List Lock executable to specific computer hardware fingerprints (space-separated list).
--name String Application and process executable name. Default: EveryThingDownloader.
--version String Release version string. Default: 1.0.0.
--icon Path Path to icon (.ico on Windows; .png or .icns on macOS).
--company String Company / developer info compiled into file resource properties.
--description String File description metadata (determines display name in Windows Task Manager).
--copyright String Copyright legal string compiled in resource properties header.
--config Path Load build configuration from a JSON file. Overrides individual command-line options.
--machine-id-info None Calculate and show the current native machine's hardware fingerprint, then exit.
--gui None Start the local build server on a free port and open the web GUI in the default browser.
Generated Output Artifacts

The compiler exports binaries and installer packages depending on your active compilation platform:

  • Web Binary (Flask server only):
    • Windows: dist/EveryThingDownloader-Web-[version].exe
    • macOS: dist/EveryThingDownloader-Web-[version] (Unix binary)
    • Linux: dist/EveryThingDownloader-Web-[version] (Unix binary)
  • Desktop Application — Windows:
    • EveryThingDownloader-Setup-[version].exe — NSIS Installer
    • EveryThingDownloader-Portable-[version].exe — Portable (no install)
    • EveryThingDownloader-[version].msi — Windows Installer (MSI)
    • EveryThingDownloader-[version]-win.zip — ZIP archive
  • Desktop Application — macOS:
    • EveryThingDownloader-[version].dmg — Disk Image installer
    • EveryThingDownloader-[version]-mac.zip — ZIP archive
    • EveryThingDownloader-[version].pkg — Package installer
  • Desktop Application — Linux:
    • EveryThingDownloader-[version].AppImage — Portable AppImage
    • EveryThingDownloader-[version].tar.gz — Archive
    • EveryThingDownloader-[version].deb — Debian/Ubuntu package
    • EveryThingDownloader-[version].rpm — Fedora/RHEL package

Cross-compilation Restriction: Cross-compilation (e.g., building macOS DMGs on Windows, or Windows EXEs on macOS) is not supported due to native PyInstaller compilation constraints. You must run this build tool natively on the target host platform.
